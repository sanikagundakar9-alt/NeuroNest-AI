# NeuroNest AI 🤖

NeuroNest AI is a modern AI-powered Study Assistant Web Application built using HTML, CSS, and JavaScript.  
The project helps students summarize notes, generate quizzes, interact with an AI chatbot, and improve learning productivity.

---

# Features ✨

- AI Notes Summarizer
- Quiz Generator
- AI Chatbot
- Voice Input Support
- PDF Upload
- Dark / Light Mode
- Download Summary
- Copy Summary
- Responsive Dashboard UI
- Typing Animation
- Notifications
- Text-to-Speech

---

# Technologies Used 🚀

- HTML5
- CSS3
- JavaScript
- Web Speech API
- Local Storage
